# Единый каркас ohrana.tech

Цель: перестать редактировать десятки самостоятельных HTML-страниц вручную, сохранив текущие URL и готовый статический HTML для поисковых систем.

## Принцип

- `site.json` — единые данные компании: телефон, email, лицензия, реквизиты, Метрика, Formspree.
- `partials/` — общие блоки сайта: шапка, футер, навигация, мобильная панель, чат.
- `layouts/` — каркасы типов страниц: услуга, объект, статья, регион.
- `pages/` — только уникальные данные и контент каждой страницы.
- `assets/` — единые CSS и JS вместо больших `<style>`/`<script>` внутри каждого HTML.
- сборка генерирует обычные `index.html` в существующие URL, поэтому поисковик получает готовый HTML без клиентской подстановки.

## Правила миграции

1. Не менять URL.
2. Контент существующей страницы переносить 1:1, если отдельно не согласовано редактирование текста.
3. Не менять рабочую форму Formspree и её имена полей.
4. Сначала мигрировать одну эталонную страницу и сравнить итоговый HTML/визуал.
5. Затем переносить однотипные страницы группами.
6. Главную страницу переносить последней.

## Рекомендуемые типы шаблонов

- `service` — физическая, пультовая, техническая охрана.
- `object` — склады, офисы, ТЦ, магазины и другие объекты.
- `region` — Москва/МО и региональные страницы.
- `article` — материалы в `/stati/`.
- `special` — контакты, договор, коммерческое предложение.

## Что это даст

Изменение телефона, меню, футера, Метрики, общих SEO-элементов или дизайна выполняется в одном месте. При этом каждая страница сохраняет собственные `title`, `description`, canonical, H1, JSON-LD и уникальный текст.
